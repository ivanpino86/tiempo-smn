# Feature: open-data

Locator: `odd/tasks/open-data.md` · Engram mirror: `odd/open-data/tasks` · Branch: `feat/open-data`

## Objective
Show current weather and forecast using the SMN official open data files instead of the token-protected API.

## Problem / Why
The SMN API (`ws1.smn.gob.ar`) needs a JWT that is only obtainable from `www.smn.gob.ar`, which is behind a Cloudflare bot challenge. Automated browsers are blocked (GitHub Actions and local PC both got HTTP 403). The token itself works from any client, but it cannot be obtained automatically. The open data files at `https://ssl.smn.gob.ar/dpd/descarga_opendata.php?file=...` need no token and no challenge (verified HTTP 200 on 2026-10-22).

## Data sources (verified)
- `estaciones/estaciones_smn.txt` — fixed-width: name, province, lat deg/min, lon deg/min, altitude, WMO number, ICAO. Wraps lines. ~120 stations.
- `observaciones/tiepreYYYYMMDD.txt` — `;`-separated, one station per line: name;date(22-octubre-2026);time;state;visibility;temp;feels("No se calcula" or number);humidity;wind("Noreste  22" / "Calma");pressure("1000.5 / ").
- `pron5d/pronYYYYMMDD.txt` — blocks per station (`CORDOBA_OBSERVATORIO` + `====` header), rows every 3 h: `22/OCT/2026 00Hs.  temp  dir | kmh  rain_mm`. Model output, 5 days.
- Names differ across the three files; no shared id. The open search endpoint returns, per location, the WMO number of its station (row index 4) and coordinates.

## Scope
- Worker reads/parses open data, caches it, maps a location (WMO + lat/lon) to a station, returns JSON shaped like the old SMN API so the UI changes stay small.
- Static station table generated by a script (estaciones + tiepre names + pron5d names), committed.
- UI: 5-day forecast with rain in mm (no rain probability, no sky description in forecast); "Mi ubicación" uses nearest station.
- Remove the token refresher, its workflow, and token code in the Worker. README updated.

## Constraints
- Cloudflare Workers runtime; no new runtime dependencies.
- Search stays a direct call to the open SMN search endpoint.
- Artifacts in English (code, comments); UI copy stays in Spanish (existing project language).
